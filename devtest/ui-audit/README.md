# 界面全面检查工具（2026-11-08）

在隔开的测试 Studio 上跑（`devtest/run.py --profile chk`：电脑 7897 / 手机 7898，数据在 `devtest/states/gpu`，不碰真实数据；端口可用 `STUDIO_TEST_PORT` 改），不用显卡。

1. `python -I devtest/run.py --profile chk`：启动测试 Studio（`seed_imgs.py` 往测试图库里放几张假图）
2. `runall.sh`：24 种尺寸（应用全屏 1280~3840、窗口 761/900/1024/1199/1200、矮窗口、浏览器、浅色、手机 375/390/393/440、横屏、iPad）每页都检查，结果在 `aud/<尺寸>/`
   - 像用户一样点导航进页面；可疑处画框截图（`*_m.png`）
   - 规则：横向溢出 / 整页被缩小、整页多余滚动、没用的小滚动条、被挡住、文字压文字、两个固定控件叠在一起、滚到底也被盖住、标题被挤走、
     文字被挤成竖排、短按钮折成两行、一排里有一项只露一半、小组件独占一行、手机点按区域太小、空白框、坏图、报错和失败的请求
   - 手机：真实触摸滑动（上下左右），还从生视频 / 作品 / 生图点开详情再滑
3. `t_validate.py`：把以前漏掉的那几类 bug 故意放回页面，每条规则都要显示“抓到了”（改了规则后必跑）
4. `states.py <尺寸>`：改视频放入原视频 + 有任务、收起右栏、展开导航、播放条展开、齿轮菜单、模式下拉、高级参数
5. `t_click.py <tag> [phone]`：每页能点的东西逐个点（第二层菜单也点），看点不点得到、报错、弹出层出屏、关不关得掉；`clicksum.py` 汇总
6. `agg.py` / `show.py` 汇总规则结果；`sheet.py` 拼图——最后一定要自己看截图（很多问题只有眼睛能发现）
7. `t_imgflow.py`（2026-11-16）：生图页的流程回归——模型选择、局部重画来回切模型（画布绑定、重复 id）、缩放涂抹、“已增强过”记号。改生图页必跑，应全部通过
8. 全面检查用全新测试数据：`STUDIO_TEST_STATE=devtest/states/chk1116 python -I seed_imgs.py`，再 `python -I devtest/run.py --profile chk --state devtest/states/chk1116`（没有真实数据，截图可看）
